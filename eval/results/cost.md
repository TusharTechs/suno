# What SUNO costs to run

Generated by `eval/cost.py` from logged Claude usage (8 notes and a brief in `samples/synthetic/demo_history.json`, real API token counts) and Sarvam's published pay-as-you-go prices.

**Assumptions:**
- ₹88 per US$
- 200 school days a year
- 30 children per class
- one 60-second note and one brief per school day

| Per school day, per teacher | Cost |
|---|---|
| Claude, reading the note (average of 8; 95% of input served from the prompt cache) | $0.034 (₹2.96) |
| Claude, wording the brief | $0.121 (₹10.68) |
| Sarvam speech-to-text, 60 s at ₹0.49/min | ₹0.49 |
| Sarvam voice for the brief, 1161 characters at ₹3/1,000 | ₹3.48 |
| **Total** | **₹17.61** |

- **Per teacher per year:** ₹3,522
- **Per child per year:** ₹117
- **Leaner configuration, same design (estimate, not measured):** brief at lower effort (assumed about 40% cheaper) and overnight batch processing at half price: about ₹8.65 a day, ₹58 per child per year.
- **One-off:** reading the attendance register from a photo costs about $0.02 per class (measured once).

Not included: hosting (a single small server serves many schools) and data (a 60-second note is about 240 KB; a brief is about 300 KB of audio).
